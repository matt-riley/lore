## Acceptance mapping

1. **Golden parser fixtures** — `tests/v2/fixtures/sources/{pi,codex,claude,antigravity}.jsonl`
   exercised by `ingestion_proof`; Copilot builds a synthetic session store at
   test time. Coverage: session headers, role attribution, tool calls, quoted
   text, compaction summaries, parent chains, side branches, step revisions,
   malformed and ignored records.
2. **Checkpoint transaction and concurrent claims** — `capture_conflicts_do_not_advance_offsets`
   proves a stale capture cannot move the checkpoint; commits are a single
   transaction so an offset never advances without its records.
3. **Append, partial UTF-8/JSON, truncation, replacement, missing source** —
   `capture_is_atomic_and_append_continues_the_generation`,
   `trailing_partial_records_are_retained_and_oversized_records_are_skipped`,
   `truncation_and_replacement_start_a_new_generation`,
   `missing_and_symlinked_sources_never_delete_evidence`.
4. **Missed notifications, restart cursor, fairness** — ingestion load proof:
   no hints are sent after the initial capture; a 5 s sweep catches up; a
   second source grows continuously while four clients work and both sources
   still reach `caught_up` with byte-exact offsets.
5. **Files above 10 MiB, oversized records, invalid middle records** — quantum
   paging removes the old 10 MiB eligibility cap; records over the ceiling are
   skipped with counts and later records still progress; malformed lines are
   counted and never materialized.
6. **Read-only SQLite source** — `copilot_sources_are_read_only` verifies
   captured rows, then confirms host bytes are unchanged and later turn
   updates are re-read; `unknown_sqlite_schema_fails_without_hot_looping`.
7. **Escaped paths, unknown roots, native ID mismatch, retired branches** —
   `missing_and_symlinked_sources_never_delete_evidence`,
   `source_identity_mismatch_is_rejected`, the route test for unapproved roots,
   and Claude branch corrections that mark side-branch evidence `abandoned`.
8. **Load capture while four clients Recall/Retain** — `daemon/tests/ingestion-load.mjs`
   (report: [`g4-load.json`](g4-load.json)): recall p95 2.61 ms, retain p95
   1.13 ms, 1501 + 351 normalized records across two sources, zero skipped,
   catch-up inside one sweep, no provider required.

Hermetic verification: `cargo test` passes 98 tests across 19 suites; clippy
`-D warnings` is clean; `node --test tests/two-client.test.mjs tests/lexical-quality.test.mjs`
passes; the ingestion load proof is in the daemon CI job.

## Semantics worth stating

- Source identity is `client + root + native identity` (canonical path when a
  client has no header identity), so renames and link swaps do not create
  duplicate memory.
- Appends compare the prefix bytes present at the prior checkpoint, so a file
  that only grew is never mistaken for a replacement; device changes with
  matching anchors resume the same generation.
- A missing file is `unavailable`: evidence stays, the source is retried every
  sweep, and only a proven replacement starts a new generation.
- Repository identity is only `repository_verified` when the approved root
  names it; hints are normalized (`owner/name` or a supported remote
  transport) and otherwise left `repository_unresolved`, so no unverified
  source can create global guidance.
- Raw paths are excluded from normal Status and logs; `includePaths: true` is
  the explicit local diagnostic.

## Known limitations

- No real-host session was captured in this repository; fixtures are synthetic
  by policy. Host/version certification remains a per-host checklist item.
- Transaction failpoints and storage fault injection are covered by atomicity
  by construction and the conflict test, not by injected I/O failures;
  power-loss durability is not certified.
- Claude branch reconstruction is bounded at 4 096 nodes; overflow is reported
  as a skip rather than guessed.
- Copilot reconciliation re-reads the session keyspace each completed pass
  (bounded at 256 sessions per page); very large stores progress over pages.
- Extraction intent is persisted and coalesced, but nothing consumes it yet:
  extraction parity belongs to stage 5A, so G4 is not closed.
- No persisted per-source backoff state: the sweep interval is the automatic
  retry bound (60 s default, 5 s minimum).
